Publications

MESC-3D: Mining Effective Semantic Cues for 3D Reconstruction from a Single Image
CVPR 2025
Accepted 已录用
Shaoming Li, Qing Cai, Songqi Kong, Runqing Tan, Heng Tong, Shiji Qiu, Yongguo Jiang, Zhi Liu

Existing methods simply concatenate image semantics with 3D point clouds, and the entangled features hold back reconstruction. MESC-3D actively mines effective semantic cues through an Effective Semantic Mining Module, and adds a 3D Semantic Prior Learning Module with learnable text prompts to compensate for occlusions…

已有方法多把图像语义与三维点云直接拼接，纠缠的特征会限制重建质量。MESC-3D 通过有效语义挖掘模块主动筛选语义线索，并引入带可学习文本提示的三维语义先验学习模块，弥补遮挡造成的信息缺失……

SMSPC: Semantic-aware Multi-class Self-supervised Point Cloud Completion
IEEE TIP 2026
Accepted 已录用
Songqi Kong, Qing Cai, Shaoming Li, Shiji Qiu, Zuoqi Hu, Xiaojun Chang, Junyu Dong

Self-supervised point cloud completion predicts missing structure without paired data, yet random sampling discards critical semantic details and class-wise models do not scale. SMSPC preserves key regions with a Gumbel Top-k sparse semantic filtering module, trains one unified model across categories, and aligns predicted features with class-specific text prompts…

自监督点云补全无需成对数据即可预测缺失结构，但随机采样容易丢失关键语义，逐类别训练也难以扩展。SMSPC 用基于 Gumbel Top-k 的稀疏语义过滤模块保留关键区域，以统一模型覆盖多个类别，并将预测语义特征与类别文本提示对齐……
